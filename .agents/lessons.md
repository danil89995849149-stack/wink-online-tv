# Память проекта: уроки и решения
[2026-10-20] Исходный плейлист содержит каналы Wink со структурой ?offset=-${offset}&utcstart=${timestamp} и заголовками WINK/1.130.1 или ExoPlayer2 -> Реализован HLS Reverse-Proxy (server/hls_proxy.js), переписывающий манифесты и инжектирующий заголовки без задержек.
[2026-10-20] Каналы Wink имеют дубли сдвигов часовых поясов (+1, +2, +3, +4, +5, +6, +7, +8, +9) -> Реализован алгоритм дедупликации и авто-выбора фида под часовой пояс пользователя Intl.DateTimeFormat (public/js/timezone.js).
[2026-10-20] Потоки Ростелеком/Wink в CDN ngenix блокируют сторонний User-Agent и запросы без CORS -> Проксирование /p?url=... обеспечивает 100% совместимость со всеми браузерами.
[2026-10-20] Запуск передачи из архива (Catch-up) активируется в один клик из EPG сетки, рассчитывая смещение от UTC epoch и выводя кнопки пропуска рекламы (+90с).
[2026-10-21] Перегрузка интерфейса категориями и нижней сеткой каналов -> Перестроено на 3-колоночную ТВ-раскладку: слева вертикальный список каналов со свободным скроллом колесиком мыши, по центру полноэкранный плеер, справа телегид EPG; категории убраны, часовой пояс скрыт в UI и подбирается автоматически под локальное время.
[2026-10-21] Хаотичный порядок каналов по алфавиту и навязчивая реклама -> Внедрена LCN-сортировка РФ (1-20 мультиплексы ГОСТ, далее федеральные развлекательные 21-30 и регионы), тихое фоновое автообновление раз в 24 часа без шума в UI, и модульная ненавязчивая промо-система приложения для ПК (public/js/promo.js).
[2026-10-22] Деплой на GitHub с токеном Fine-Grained PAT (PAT v2) -> GitHub API блокирует создание персональных репозиториев через Fine-grained PAT (403 forbidden), бинарники >100MB (*.exe) и кэш EPG (>90MB) обязательно исключаются в .gitignore, пуш выполняется автоматически через deploy_to_github.ps1 и git credentials.
[2026-10-22] Анализ 3400+ каналов внешнего плейлиста и юридическая безопасность РФ -> Жесткая фильтрация Красной зоны (18+, платный спорт «Матч Премьер/Футбол», подписочное кино Amedia/Viju), удаление нерабочих локальных AceStream потоков (127.0.0.1), приоритет Wink-каналам с архивом сверху по ГОСТ LCN (1-20 мультиплексы), EPG-каналам в середине и каналам без EPG снизу.
[2026-10-22] SEO и мультистраничность онлайн ТВ -> Внедрены SSR ЧПУ-роуты /channel/:slug с динамической микроразметкой Schema.org BroadcastEvent и VideoObject, sitemap.xml и robots.txt; скрыт выбор часового пояса и звезда избранного, добавлены фильтры-чипы (Все, HD, Архив, С программой).
[2026-10-22] Одноколоночная навигация, внутриоконный плеер и 100% покрытие логотипами -> Убраны разделители HD/с программой в пользу единого монолитного списка каналов; в плеере реализованы центральные кнопки [⏮] [▶] [⏭], экранный OSD поверх видео и выезжающий внутриоконный сайдбар (#playerSidebar) по кнопке и клавише 'C'; логотипы обогащены через базу external_logos.js (19 372 лого) и динамические SVG-градиенты, гарантируя 100% покрытие для всех 730 каналов.
[2026-10-22] Очистка интерфейса плеера от лишних контролов -> Полностью удалены кнопки перемотки на 10 и 30 сек, кнопка пропуска рекламы (+90с) и выпадающий список скорости воспроизведения; навигация на стрелки клавиатуры ← и → перенаправлена на плавное переключение телеканалов.
[2026-10-22] Исправление горизонтального смещения плеера и дедупликация -> Нативный scrollIntoView() на скрытом элементе с translateX(100%) прокручивал всё окно вправо, создавая чёрную полосу и сдвигая видео; заменено на безопасный scrollTo({top}) контейнера и display:none; удалены дубликаты каналов (Пятница, Мир, Че, Муз ТВ и др., 722 каналов), каналы со сдвигом часовых поясов (+2, +4, +7) помещены строго в самый низ списка.
