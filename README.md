# Wink TV Replay — Онлайн ТВ с архивом передач и умным часовым поясом

Премиальный веб-сервис онлайн-телевидения с глубокой поддержкой архива телепередач (Catch-up / Timeshift / Replay TV) до 3 суток (72 часов) на базе потоков провайдера **Wink (Ростелеком)**.

---

## 🌟 Ключевые возможности

### 1. Интеллектуальный часовой пояс (Smart Timezone & Feed Auto-Matching)
- **Устранение хаоса дублей**: Вместо загромождения каталога десятками версий каналов (`+1`, `+2`, `+3`, `+4`, `+5`, `+6`, `+7`, `+8`, `+9`) система агрегирует их в единые карточки.
- **Авто-сопоставление**: Сервис автоматически определяет часовой пояс пользователя (`Intl.DateTimeFormat`) и подает в плеер фид, смещение которого точно совпадает с местным временем зрителя (например, для Екатеринбурга `МСК+2`, для Красноярска `МСК+4`, для Владивостока `МСК+7`).
- **Переключатель фидов («Машина времени»)**: Прямо в плеере зритель может в 1 клик переключить канал на любой другой часовой пояс, чтобы посмотреть вечернее шоу на несколько часов раньше или позже.

### 2. Архив передач (Catch-up до 72 часов)
- **Просмотр пропущенных программ**: В боковой панели телегида (EPG) отображаются все передачи за последние 3 дня.
- **Запуск в один клик**: Кликнув по любой прошедшей передаче со значком `⏪ Запись`, плеер мгновенно запускает её просмотр с начала.
- **Память позиции**: Если просмотр передачи был прерван, плеер сохраняет позицию и при повторном включении возобновляет воспроизведение с нужной секунды.

### 3. Умная перемотка и пропуск рекламы (Commercial Skip)
- Специальная кнопка **`⏩ Пропустить рекламу (+90с)`** позволяет одним нажатием перемотать стандартный рекламный блок на телевидении.
- Кнопки точной перемотки `↺ 10с`, `↺ 30с`, `10с ↻`, `30с ↻`.
- Интерактивный скраббер/таймлайн с отображением прошедшего и оставшегося времени передачи.
- Кнопка **`🔴 В прямой эфир`** для мгновенного возврата к живому вещанию из режима архива.

### 4. Полноценный телегид (EPG)
- Интерактивное расписание с разбивкой по дням (Сегодня, Вчера, Позавчера, Завтра).
- Индикатор **`● В эфире`** с живым прогресс-баром прошедшего времени текущей передачи.
- Адаптация времени всех передач под локальный часовой пояс пользователя.

### 5. Автоматическое обновление плейлиста
- Модуль периодической фоновой синхронизации (каждые 2 часа) подтягивает свежие потоки и манифесты.
- Кнопка ручного обновления **`🔄 Обновить базу`** в шапке сайта.
- Локальное дисковое кэширование гарантирует мгновенный запуск сайта даже при сбоях внешней сети.

### 6. Премиальный кинематографичный дизайн
- Тёмная кинематографичная тема с эффектом матового стекла (Glassmorphism), плавными градиентами и тенями.
- Категории каналов: *Общероссийские, Кино и сериалы, Познавательные, Развлекательные, Детские, Спорт, Музыка, Информационные, Региональные*.
- Раздел *⭐ Избранное*.
- Быстрый поиск по названию канала и текущей передаче.
- Поддержка горячих клавиш (`Space` — пауза, `←/→` — перемотка, `F` — полный экран, `M` — звук, `/` — поиск).

## 🚀 Быстрый запуск

### Требования
- Установленный **Node.js** (версия 18+).

### Запуск
```bash
# 1. Запуск сервера
npm start
# или
node server/server.js
```

После запуска откройте браузер по адресу:
👉 **`http://localhost:8900`**

## 📺 Контракты API

- `GET /api/channels` — список всех агрегированных каналов Wink с фидами и логотипами.
- `GET /api/epg?tvgId=...&name=...&date=YYYY-MM-DD` — расписание передач канала.
- `GET /api/epg/current` — текущие передачи для всех каналов.
- `POST /api/playlist/refresh` — принудительное обновление плейлиста.
- `GET /p?url=<URL>&ua=<UA>` — стриминговый прокси видеопотока.
